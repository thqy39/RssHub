# RSSHub

一个轻量的 RSS 订阅器，支持订阅源、阅读状态、实时刷新和阅读列表管理。

## 运行

1. 安装依赖

```bash
npm install
```

2. 启动服务

```bash
npm start
```

3. 打开浏览器访问

```
http://localhost:4000
```

## 功能

- 添加 / 删除 RSS 订阅
- 刷新订阅并拉取最新文章
- 标记已读 / 未读
- 按订阅源和未读状态筛选

## 开发说明

- `server.js` 为 API 服务和静态页面服务器
- `public/` 为前端静态页面
- `data.json` 保存用户订阅与文章缓存数据
