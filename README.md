# RSSHub

一个轻量的 RSS / Atom 聚合阅读器。订阅和文章缓存在本机，以阅读、筛选和快速更新为核心。

## 运行

1. 安装依赖

```bash
npm install
```

2. 启动服务

```bash
npm start
```

3. 打开浏览器访问

```
http://localhost:4000
```

## 功能

- 添加 / 删除订阅，支持 RSS 与 Atom
- 单源刷新、手动刷新全部，并每 15 分钟自动刷新（页面打开且处于前台时）
- 全文预览、原文跳转、未读计数、单篇及批量标记已读
- 按订阅源和未读状态筛选，搜索标题与摘要
- OPML 订阅导入与导出，便于从其他阅读器迁移或备份订阅清单
- 订阅和文章缓存保存在本机 `data.json`

## 开发说明

- `server.js` 为 API 服务和静态页面服务器
- `public/` 为前端静态页面
- `data.json` 保存本机订阅与文章缓存；建议定期备份。OPML 只包含订阅清单，不包含文章和阅读状态。
